USPTO Trademark Filing Fees After 2025: The Base Application and Surcharges

If you researched trademark filing a few years ago, you probably read about two USPTO application options: TEAS Plus and TEAS Standard. That system is gone. Since January 18, 2025, the USPTO has used a single base application for applications filed under Sections 1 and 44 of the Trademark Act, plus additional fees (surcharges) when an application is incomplete or uses custom wording for goods and services. Here is how it works now and how Florida applicants can keep filing costs predictable.

What Changed

Under the USPTO’s fiscal year 2025 fee rule, the two prior electronic application fees, TEAS Plus ($250 per class) and TEAS Standard ($350 per class), were replaced by one base application fee. The change took effect on January 18, 2025 for fees paid to the USPTO. The USPTO has said it expects most applicants to pay only the base fee and no additional fees.

The Base Application Fee

The base application fee is $350 per class of goods or services, as long as the application meets the base application requirements. Fees are calculated per class, so an application covering one class costs $350 and an application covering goods in one class and services in another costs $700, before any additional fees.

The Three Additional Fees

  • Insufficient information: $100 per class. Charged when the application leaves out information required for a base application, such as the applicant’s domicile address, legal entity type, or a properly signed declaration. Depending on the mark, required information can also include an English translation of non-English wording, written consent from a named living individual, or a color claim and description. The fee is assessed on all active classes and is usually paid at filing, though an examining attorney can also assess it during examination.
  • Free-form text instead of the ID Manual: $200 per class. Charged when you describe your goods or services in the free-form text box instead of selecting entries directly from the Trademark ID Manual in Trademark Center. Copying ID Manual wording and pasting it into the free-form box still triggers the fee. Leaving a fill-in-the-blank ID Manual entry empty, or filling it with unrelated or clearly inappropriate content, can also result in this fee.
  • Each additional 1,000 characters: $200 per affected class. If a class’s free-form identification goes beyond the first 1,000 characters (counting spaces and punctuation), you pay $200 for each additional group of 1,000 characters in that class. Once a class has any free-form text, the USPTO counts all characters in that class, including entries you picked from the ID Manual.

For example, a one-class application with a 1,001-character free-form identification costs $350 base + $200 free-form fee + $200 excess-character fee = $750 in USPTO fees, compared with $350 if the same goods could be identified with ID Manual entries.

Practical Tips to Avoid Surcharges

  • Use ID Manual entries where they fit. Select them directly in Trademark Center rather than pasting them in. Many common products and services already have acceptable entries.
  • Keep descriptions precise. Free-form wording makes sense when no entry accurately covers what you sell. If you need it, write clearly and concisely; long, padded identifications cost more and invite examination issues.
  • Complete every fill-in-the-blank field with content that actually matches the selected entry.
  • Gather required details before filing: domicile address, entity type, translations, consents, and color claims if they apply.
  • Count classes carefully. Every class carries its own base fee and its own possible surcharges.

Trademark Center shows an additional-fee acknowledgment when you leave out required information or use the free-form box, and it displays a character counter. Read those prompts before you submit.

Other Fees to Plan For

The filing fee is only part of the budget. Intent-to-use applicants later pay $150 per class for a statement of use or amendment to allege use, and $125 per class for each extension request. USPTO fees can change, so confirm current amounts on the USPTO trademark fee information page before you file. Attorney fees are separate from USPTO fees.
